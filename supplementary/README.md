# Supplementary materials

Supplementary tables published with Begum et al. (2025) *Antonie van Leeuwenhoek*
118:183 (doi:10.1007/s10482-025-02195-5). Included here for convenience; the
journal version is the version of record.

| File | Contents |
|------|----------|
| `Supplementary_Table_S1.docx` | Fish feed ingredients used in the 90-day oxytetracycline-exposure experiment (per 1 kg feed). |
| `Supplementary_Table_S2.docx` | The 12 cultured bacterial isolates: GenBank accession, species, amplified base pairs, NCBI match (%), and condition (control/treated). |
| `Supplementary_Table_S3.docx` | Antibiotic (oxytetracycline, 30 µg disc) sensitivity test of 26 gut bacterial isolates by disc diffusion; scored Sensitive / Intermediate / Resistant. |
| `Supplementary_Table_S4.xlsx` | Shotgun OTU table — sheet *Read Counts & Taxonomy* (per-sample read counts) and sheet *Relative_Abundance* (per-species relative abundance). Samples: **CR1, CR2** (controls) and **TR1, TR2, TR3** (oxytetracycline-treated). |
| `S4_read_counts_taxonomy.csv` | CSV export of the *Read Counts & Taxonomy* sheet of S4 (open, machine-readable). |
| `S4_relative_abundance.csv` | CSV export of the *Relative_Abundance* sheet of S4 (open, machine-readable). |

**Canonical sample labels.** The paper and Table S4 use **CR1, CR2** (controls)
and **TR1, TR2, TR3** (treated). These correspond to the five SRA runs of
BioProject PRJNA1282882 via the run titles (*Control1/Control2* and
*Dose1/Dose2/Dose3*). The internal labels used inside the original processing
script (`Control_S1`, `Control_S8`, `SingleAbx_S2`–`S4`) map onto the same five
samples, but the exact one-to-one assignment to CR/TR was not recorded and should
be confirmed by the authors. See `docs/REPRODUCIBILITY.md`.
